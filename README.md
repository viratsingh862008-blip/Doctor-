# Dr. Mugdha Mohan — WebTea HQ

A production-oriented dermatologist website prototype for Skin Care Centre (Dr. Mugdha Mohan), Bettiah.

## Stack

Next.js + TypeScript + GSAP + Zod + Lucide.

## Patient funnel

Search / social → doctor authority → condition education → appointment enquiry → WhatsApp confirmation.

## Included

- Responsive editorial medical design
- Doctor and clinic imagery from public listings for proof-of-concept
- Local SEO metadata + Physician JSON-LD
- Sitemap + robots
- Condition-led discovery sections
- Procedure/service presentation
- Research/academic authority block
- Public-review proof section
- WhatsApp CTAs
- Appointment enquiry form with server-side validation
- Reduced-motion support and mobile navigation

## Run

```bash
npm install
npm run test
npm run build
npm run dev
```

## Production handoff

Public source material was researched for the demo. Confirm clinic-owned image rights, exact clinic hours, phone number, social handles and final medical copy with Dr. Mugdha Mohan before launch. Replace third-party imagery with clinic-owned originals when available.
